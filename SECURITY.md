# Security

GhostLink is experimental software for local development and test networks. The proving setup is deliberately insecure, the code has not had an independent security audit, and this release is not approved for real funds.

Before running it, read [the threat model](docs/THREAT-MODEL.md). No hosted service, mainnet support or security response SLA is provided.

Use GitHub's private vulnerability reporting feature if the repository's Security tab offers it. If it is unavailable, open an issue requesting a private contact without including exploit details, credentials or affected users' information. Do not post live secrets or test a report against third-party deployments.

Reports should identify the affected revision, component, expected and observed behavior, and a minimal local reproduction when safe. Keep tests on an isolated local validator with disposable assets.
